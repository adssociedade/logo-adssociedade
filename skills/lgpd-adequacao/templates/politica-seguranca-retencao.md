# Política Interna de Privacidade, Segurança da Informação e Retenção — [[EMPRESA]]

> **Instrução (apagar):** documento interno, para empregados. As medidas técnicas são **requisitos** que a TI do cliente deve implementar; o advogado não atesta que estão implementadas. Usar o Guia de Segurança da Informação da ANPD como referência mínima.

## 1. Objetivo e alcance
Regras para proteger dados pessoais tratados pela empresa. Vale para empregados, estagiários, prestadores e qualquer pessoa com acesso a sistemas ou documentos.

## 2. Princípios
Usar só o dado necessário, só para a finalidade do trabalho, só pelo tempo necessário.

## 3. Regras para todos
1. Login e senha **pessoais e intransferíveis**; senha forte; duplo fator onde houver.
2. Bloquear a tela ao sair da mesa. Mesa limpa: documentos com dados pessoais guardados ao fim do dia.
3. **Proibido** enviar dados de clientes ou colegas para e-mail pessoal, WhatsApp pessoal, pen drive ou nuvem pessoal.
4. Dados de saúde (receitas, laudos, atestados) só podem ser acessados por [[cargos]].
5. Conferir o destinatário antes de enviar e-mail com anexos.
6. Desconfiar de e-mails/mensagens pedindo senha, pagamento ou dados — avisar a TI.
7. Incidente ou suspeita → avisar o encarregado imediatamente.
8. Descartar papel com dados em fragmentadora.

## 4. Requisitos técnicos (responsável: TI — [[nome/fornecedor]])
- Controle de acesso por perfil; revisão [[semestral]]; remoção de acessos no dia do desligamento.
- Duplo fator em e-mail, ERP e acessos remotos.
- Backup [[diário]], com cópia isolada e teste de restauração [[trimestral]].
- Atualizações de sistema e antivírus em todos os equipamentos.
- Criptografia de notebooks e celulares corporativos.
- Registro (logs) de acesso aos sistemas com dados sensíveis.
- Wi-Fi de visitantes separado da rede interna.
